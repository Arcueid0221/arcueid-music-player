# 后续指导方针

## 设计与架构原则

1. `player-element.ts` 只做属性/方法适配，不再放歌单数据、DOM 拼装或音频事件。
2. 播放行为先写在 `core/`，视觉行为写在 `ui/`；网络与持久化统一放进 `services/`。
3. 状态只有一个来源：界面从 store 渲染，不直接猜测 `<audio>` 的状态。
4. 新功能优先增加小而可替换的服务，不把云端 API、歌词解析、缓存和 UI 写在同一文件。
5. 每个纯逻辑模块都配单元测试；播放器主路径用浏览器交互测试覆盖。

## 功能阶段

### P1：把播放器做稳（已完成）

- 已增加缓冲进度采集、波形轨道、网络失败重试、无效音频跳过与明确错误操作。
- 已补齐 Controller 状态机、移动端进度拖动和键盘主路径验证。

### P2：系统媒体与后台恢复（已完成）

- 独立 Media Session 服务负责系统媒体键、锁屏元数据、播放状态与位置同步。
- 支持系统播放、暂停、停止、前后切歌、快进快退和指定位置跳转。
- 页面进入后台或触发 `pagehide` 时立即保存播放记忆。
- 页面恢复可见或从 BFCache 返回时，根据“播放意图”恢复音频输出；用户显式暂停后不会误播放。

### P3：播放队列与数据源（已完成）

- `PlaylistProvider` 已支持本地数组、JSON API 和用户选择 JSON 文件。
- 队列支持歌曲追加、删除、按钮排序和拖拽排序。
- 支持按歌曲、歌手和专辑搜索，并在打开队列或切歌后自动定位当前歌曲。
- Web Component 提供 `playlist-src`、`loadPlaylist()`、`addSongs()`、`removeSong()` 与 `moveSong()` 等接入方式。

### P4：体验扩展（已完成）

- 已增加主题 token、深色主题与跟随系统主题，业务组件不感知具体颜色。
- 已支持逐字歌词、歌词偏移校准与无歌词降级。
- 已增加网络失败重试、无效音频自动跳过和明确的错误恢复入口。

### P5：面向复用与发布（已完成）

- 已增加 `createMusicPlayer()`，支持自定义挂载点、生命周期钩子和多实例隔离。
- 已提供稳定事件 API：`ready`、`trackchange`、`playbackchange`、`error`。
- 已产出 ESM/IIFE、类型声明、最小接入示例和版本迁移说明。
- 已补齐跨域音频、SSR 动态加载和浏览器兼容策略。

### P6：访客端只读化（已完成）

- 已增加 `playlist-mode="readonly|editable"`，默认使用面向博客访客的 `readonly`。
- 只读模式禁用 JSON 文件导入、删除歌曲、按钮排序和拖拽永久排序；事件层也会拒绝这些管理动作。
- 保留歌单浏览、搜索、当前歌曲定位和选择播放。
- 保留底层 `PlaylistProvider`、JSON 规范化、文件 Provider 和队列领域能力，供宿主或未来 Blog Admin 复用。
- 明确“宿主配置播放器”和“访客管理内容”的差别：宿主可以注入数据，访客端不提供写入口。

### P7：博客公共音乐 API（计划中）

- 明确 Track、Playlist、PlaylistTrack 和公开响应模型。
- 增加面向博客只读 GET API 的 Provider/Adapter，并支持默认歌单或指定歌单 ID。
- 播放器不接触数据库和管理凭据；Admin 写接口由博客后台实现并认证。

### P8：浮动播放器与博客容器（计划中）

- 支持展开/收缩、左右侧停靠、鼠标/触屏拖拽和视口边界限制。
- 可选记忆位置、收缩状态和停靠侧，适配移动端安全区域。
- 使用独立拖拽手柄，避免与波形、音量和歌词滚动手势冲突。

### P9：宿主接入与发布（计划中）

- 提供静态博客与 SPA 接入示例，确保路由切换不重复创建播放器或中断播放。
- 验证公开 API、音频、歌词和封面的 CORS、Range 与缓存策略。
- 确定博客本地构建、CDN 或 npm 包发布方式，并完成相关文档。

详细边界、数据模型和 API 设计见 [`BLOG-MUSIC-ARCHITECTURE.md`](./BLOG-MUSIC-ARCHITECTURE.md)。

## 当前验收边界

- 现有自动化测试、生产构建和浏览器审核结果视为当前播放内核通过。
- 真实 macOS Safari/iOS Safari 的音量、锁屏和后台行为仍建议发布前抽查，但不再阻塞 P6–P9 开发。

## 明确延后

- 云端账号、收藏同步、推荐算法与数据库不应进入播放器内核。
- 樱花等页面级特效做成独立插件，不与播放生命周期绑定。
- 在基础播放链路稳定前，不引入大型框架或完整状态管理库。
